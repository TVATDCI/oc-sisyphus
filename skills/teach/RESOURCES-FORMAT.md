# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for this topic. Knowledge for explainers should be drawn from here, not from parametric guesses. Wisdom comes from the communities listed here.

## Structure
# {Topic} Resources
## Knowledge
- [Book: _The Science and Practice of Strength Training_ — Zatsiorsky & Kraemer](https://example.com)
  Foundational text. Use for: periodisation, recovery, intensity zones.
## Wisdom (Communities)
- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit. Use for: programme critique.

## Rules
- High-trust only.
- Annotate every entry.
- Group by Knowledge / Wisdom.
- Surface gaps explicitly via `## Gaps`.
- Prune ruthlessly.
- Record community preferences.
